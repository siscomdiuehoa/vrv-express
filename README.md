# VRV Express project

The application is VRV-Project.html. Open it in a browser to use or edit it.

The analysis folder contains Ghidra and PyGhidra scripts used while investigating Xpress DIL. These require a separately installed Ghidra, compatible Java and access to the original local Xpress executable or Ghidra project. Paths in the scripts may need adjustment.

The application includes preliminary piping and equipment selection calculations. Check model-specific data and results against Daikin documentation and Xpress.

Daikin Vietnam catalogue: https://www.daikincatalog.com/library/books/dav_0006/book/data/all_page.pdf
